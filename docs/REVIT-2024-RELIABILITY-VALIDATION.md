# Revit 2024: проверка надёжного выполнения, 12 октября 2026

## Среда и пределы проверки

Autodesk Revit 2024 **24.0.4.427**, установленный API .NET Framework 4.8.
Revit не обновлялся. Все живые проверки выполнялись на отдельных моделях,
созданных тестовым модулем; пользовательские проекты не использовались.

Исходная версия 2.3.0 из коммита `2ac8227` прошла 45 из 48 сценариев:
два workflow завершили шаги, но общий валидатор отверг их статус `per_step`;
один сценарий недоступен из-за отсутствия сервисов Fabrication.

Исправление `2724de7` сверяет агрегированный результат с фактическими ответами
каждого дочернего инструмента. Обычные транзакции по-прежнему требуют
подтверждённого завершения; неизвестный статус не считается успехом.
Дополнение `5019d2c` возвращает неопределённый результат при повреждённой
структуре ответа, без исключения при преобразовании JSON.

## Выполненные проверки

- 5 897 тестов ядра и 1 054 теста MCP-сервера пройдены.
- 108 целевых проверок workflow и классификации результатов пройдены.
- Надстройка и живой тестовый модуль собраны с нулём ошибок и предупреждений.
  При сборке тестов ядра остаются существующие предупреждения анализатора xUnit.
- Каталог, публичные версии, целостность манифеста, ссылки живых тестов и
  отсутствие затенения параметров PowerShell прошли проверку.
- В русском и английском интерфейсе: **47 passed, 0 failed,
  1 unavailable_dependency** в каждом запуске.
- В обоих запусках через настоящий MCP-сервер проверены health, каталог,
  предварительный просмотр, применение и повтор обычной записи.
- Workflow через MCP проверен с переключением документов, ссылками на результаты
  предыдущих шагов и повтором после смены активного документа. Повтор вернул
  исходный ID, а не создал второй элемент.
- При ошибке второго шага сохранены первый шаг и журнал; повтор вернул тот же
  частичный результат без повторного создания элемента.

Живые прогоны RUS/ENU выполнены на `2724de7`; защита формата из `5019d2c`
покрыта отдельными отрицательными тестами. Проверка установленного билда из
объединённого main проводится отдельно после установки и не выводится из CI.

## Новые живые сценарии

1. Пять последовательных снимков 3D-вида с восстановлением камеры и флагов.
2. Снимок плана с восстановлением настроек.
3. Проём в повёрнутой стене: проверка хозяина, границ и физического объёма выреза.
4. Неразмещённое помещение и отсутствующий 64-битный ID в снимке данных.
5. Коннектор без явного назначения primary.
6. Два коннектора с явным назначением primary после создания.
7. Подготовка неактивного проекта и передача созданного ID следующему шагу.
8. Остановка после частичного выполнения с сохранением результата первого шага.
9. Отклонение подтверждения после изменения модели.
10. Подготовка документа семейства и подтверждение переименования типа.
11. Python: UTF-8 с BOM, кириллица и безопасный обход отсутствующих границ.

## Что не подтверждено

Fabrication load/create/convert не проверены на живой конфигурации: сервисы
Fabrication отсутствуют. Проверена только диагностика этой зависимости.
Количество инструментов в каталоге не равно количеству проверенных сценариев.
Эти результаты не гарантируют выполнение произвольного запроса: неверные данные,
ограничения API, права и внешние зависимости остаются основаниями для отказа.
